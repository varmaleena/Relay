# English narration for the core demonstration

Use the actual captured sequence; do not imply the optional voice, Studio or
linking flow appears in the text recording. Check duration and current portal
requirements before upload. This script is suggested narration, not a transcript.

Relay helps a person who has just been scammed organize what happened and prepare
their next step. This demonstration uses fictional details only.

The user describes an impersonation call and a forty-five-thousand-rupee UPI
payment. Relay starts with immediate safety instructions, then gathers the
details. The user can inspect and correct the amount, currency, payment method
and whether they authorized the payment. Relay never needs an OTP or password.

Next, Relay proposes a contact order using the confirmed facts and referenced
source passages. The guidance in this prototype remains clearly marked as an
unreviewed draft. It is not a guarantee of recovery or a human legal opinion.

The report workflow uses the real Google model service and background jobs.
Each report goes through fact, source and verification checks. The user reviews
the current version and can download a PDF for self-submission through the
recipient's listed channel. A download does not file a complaint.

The development prototype runs on Firebase Hosting, authenticated Cloud Run,
Firestore and private Cloud Storage. Firebase sign-in, App Check and ownership
checks protect the case. Any optional bank, police or payment-rail actions are
explicitly simulated and require the applicable approval.

The evidence page separates functional hosted checks from unmeasured comparative
quality scores. Our engineering and voice work still has open reliability and
human-review gates. Relay's demonstrated value is a reviewable account, a clear
proposed plan and a recipient-specific report the person controls.
