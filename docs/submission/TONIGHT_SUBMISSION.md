## Submission README copy

Relay helps someone who has just been scammed organize an accurate account,
understand a proposed contact order and prepare a report for each recipient.
The primary journey is **Tell us → Plan → Prepare report → Review → Copy/PDF**.
The user submits the report themselves through the recipient's listed channel.
Copying or downloading does not file a complaint or confirm official acceptance.

The prototype uses Google Gemini through the Google GenAI SDK, ADK workflows,
Firebase authentication/App Check, Firestore, private Cloud Storage and Cloud Run.
Grounded report drafting combines confirmed facts and source passages with
deterministic checks and model verification. An automated VERIFIED report is not
a human-reviewed legal opinion or a guarantee of recovery. Jurisdiction guidance
in the demonstration remains visibly unreviewed draft material.

An optional receiver demonstration uses explicit version-bound user approval and
fictional institution accounts. Its tickets, requests for information,
acknowledgments and holds are simulated. Relay sends no real bank email, police
report or payment-rail instruction in this demonstration.
