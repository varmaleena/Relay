# Packet PDF font

Noto Sans Devanagari variable TrueType font downloaded from Google's official
fonts repository on 15 October 2026:
https://github.com/google/fonts/tree/main/ofl/notosansdevanagari

Files: NotoSansDevanagari[wdth,wght].ttf (stored as NotoSansDevanagari.ttf)
and OFL.txt. Redistribution is under the included SIL Open Font License.
ReportLab 4.4.9 loads this font directly; uharfbuzz 0.56.3 performs shaping.
No fontTools conversion or external font service is needed at runtime.
